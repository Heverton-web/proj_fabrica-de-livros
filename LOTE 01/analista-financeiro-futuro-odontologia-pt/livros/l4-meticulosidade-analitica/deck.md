# Objetivo

Apresentar o poder da IA para cruzar milhares de linhas de faturamento e encontrar erros que o olho humano jamais veria — a promessa da meticulosidade analítica.

# Auditoria e Limpeza

> Estágio 1 de 2

# Caçando Descontos Ocultos

*Ensinar o leitor a cruzar duas grandes bases de dados para auditar descontos não autorizados pela equipe comercial*

- O problema dos descontos não autorizados: €45.000 em margem recuperável em distribuidoras odontológicas
- Técnica de cruzamento: join de duas tabelas por SKU + cliente + período
- Prompt para IA: como instruir o cruzamento e interpretar as anomalias

# Limpeza e Higienização de Dados (Regex)

*Usar IA para criar expressões regulares que padronizam instantaneamente milhares de cadastros e telefones de clínicas portuguesas*

- Regex para telefones PT: ^(\+351)?\s?\d{8}$ e NIFs: ^\d{9}$
- Prompt para IA: como pedir regex que limpa dados odontológicos específicos
- Antes/depois: demonstração visual do impacto da limpeza em milhares de registros

# Análise e Recuperação

> Estágio 2 de 2

# A Análise da Cesta de Compras

*Instruir a IA a analisar históricos de compras para descobrir correlações invisíveis entre produtos odontológicos*

- Algoritmo Apriori vs. FPGrowth: qual usar para catálogos B2B odontológicos
- Padrão descoberto: 67% das clínicas que compram implantes tipo A levam resinas de impressão 3D
- Prompt para market basket analysis: como estruturar o pedido para a IA

# O Relatório de Recuperação de Lucro

*Transformar anomalias encontradas pela IA em um relatório executivo de uma página focado na recuperação de margem de lucro*

- Estrutura do relatório executivo de 1 página: problema → evidência → impacto → ação
- Isolation Forest + Autoencoders: como a IA detecta anomalias em faturamento multidimensional
- Do achado à recomendação: traduzir descobertas técnicas em linguagem de negócios
